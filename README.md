# What Should We Do?

A mobile-first Birmingham date/activity roulette.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/background.jpg`
- `assets/note-paper.png`

Upload all files and the `assets` folder to the root of a GitHub repository, then deploy with Netlify or GitHub Pages.

The app uses Roboto Mono only. Saved ideas and completed ideas are stored locally in the browser.
